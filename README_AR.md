# مشهد — مشروع Flutter عربي

تطبيق تجريبي لاستعراض الأفلام والمسلسلات بواجهة عربية داكنة، مناسب للفتح في بيئة Flutter مثل KlenCodeIDE.

## الموجود في النسخة
- واجهة RTL باللغة العربية.
- قائمة أفلام ومسلسلات تجريبية.
- بحث بالاسم وتصنيف حسب النوع.
- صفحة تفاصيل لكل عنوان.
- قائمة مشاهدة محفوظة محلياً أثناء تشغيل التطبيق.
- تصميم متجاوب مبدئياً باستخدام عناصر Flutter القياسية.

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد `mashhad_app` في بيئة Flutter.
3. نفّذ `flutter pub get`.
4. شغّل التطبيق على محاكي أو جهاز Android.

أوامر الطرفية عند توفر Flutter:
```bash
flutter pub get
flutter run
```

## مهم
هذه نسخة أولية للواجهة فقط، وليست خدمة بث كاملة. لا تتضمن فيديوهات أو روابط مشاهدة. لتحويلها إلى تطبيق حقيقي، تحتاج إلى مصدر محتوى مرخّص، وروابط تشغيل فعلية، ومشغّل فيديو، وخلفية لإدارة المحتوى والمستخدمين عند الحاجة. لا تستخدم روابط مقرصنة أو محتوى لا تملك حق توزيعه.
